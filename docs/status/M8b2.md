## Things found on the way

- A closed base-ui Select picks an option by typing (typeahead). With the new-tag Preset focused, typing `40` for a circle chose "0.32mm SPEED …" instead of the sticker printer. The kit's Select now ignores letters while closed, so a tool's keys reach the tool (the M6b.1 test covers it).
- base-ui keeps a closed Select's list in the page (hidden). The app's "a list is open" check reads `[data-kit-popup][data-open]`.
