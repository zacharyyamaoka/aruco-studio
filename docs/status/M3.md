# M3 status: the Studio web app

Built 2026-10-16 on `main` in ROOT, beside the M4 (Fusion adapter) agent on other paths. The work order asked for PLAN's M3 plus the preset Library (PLAN had it in M5), e2e in `ROOT/e2e` and screenshots in `reports/screens/`.

## In one paragraph

`studio/` is a Vite + React + TypeScript app on the server's API. The 2D canvas works like Figma and draws each tag from its `TagPlan`: OpenCV reads every tag's ids back off a screenshot of the canvas. The 3D view extrudes the server's mesh; the 2D / 3D toggle keeps the centre within 1 px. The inspector is built from `/api/form`, with each `Issue` under its field and one summary line. The Library, Renumber, Verify, Export and scene files all work on the real server. 12 Playwright tests and 16 vitest tests pass; 33 screenshots are in `reports/screens/`.

## Where the build differs from PLAN / ARCHITECTURE

| PLAN / ARCHITECTURE said | Built as | Why |
|---|---|---|
| e2e in `studio/e2e/`, screenshots in `reports/e2e/` | `ROOT/e2e/` (its own package), `reports/screens/` | the work order |
| the Library in M5 | built now (`studio/src/library/`, `server/library.py`) | the work order |
| M3 may not edit `server/` or `tools/check.py` | additive server routes; `check.py` finds `e2e/` | the work order allows both |
| 2D draws the layers | 2D fills the plan's **top view** (`?top=1`: `plan/mesh.top`, what prints seen from above) and draws every layer as an outline path with `data-layer` | a layer is a CSG step (a sub step removes, a cut is not ink); filling layers in order would draw what is not printed. The top view is the core's own flattening |
| one path element per polygon | one path per layer (polygons with holes, evenodd) | fewer DOM nodes; tests read `d` |
| Playwright downloads a browser | the installed Chrome (`channel: "chrome"`, swiftshader for WebGL) | browsers are not npm packages; nothing downloaded |
| `window.__studio` in dev builds | in every build | the served-build test reads it; it holds no secrets |

## Server additions (additive; tests in `tests/server/test_studio_api.py`)

| Route | Does |
|---|---|
| `POST /api/new` | a fresh tag's TagSpec as today's dialog stores it: `origin_v` 2, label `rule` 2, `cells` from the preset, Auto Extrude resolved against the target; no adapter keys |
| `POST /api/target` | the target editor: box, disc or a palette face, round holes, a thickness |
| `POST /api/preset/apply`, `/api/preset/of` | a preset onto a tag (layout, ids, size, Origin, target kept) and back; `preset_of(apply(p)) == p` |
| `GET /api/library`, `POST /api/library/select`, `/save`, `GET/POST /api/library/recent` | REF `aruco_preset_library.Library` on the Studio's store (a PrusaSlicer card is imported on Select) |
| `?top=1` on `/api/plan` and `/api/scene` | the top view per colour |
| `image` in `/api/verify`, `inline=1` on scene exports, `origin` words in `/api/options` | the raster OpenCV read; downloads; REF's Origin words |
