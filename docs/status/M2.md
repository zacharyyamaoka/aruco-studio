# M2 status: plan, scene, verify, exports, server

Built 2026-10-16 on `main` in ROOT. REF = cad-exporter `aruco-fusion-plugin-0e9bcb`, pinned at `c8216ff`, read only. The work order asked for PLAN's M2 and M2b together; the choices are in PLAN section 8.

## In one paragraph

`plan_tag(TagSpec) -> TagPlan` is REF's `aruco_feature.evaluate()` as a pure function of numbers. 824 evaluate() goldens made by REF's own code (786 new + REF's 12 cells and 26 trim cases) replay **exactly**, floats and the sign of every zero. The plan carries the layers as REF's temporary bodies step by step, the OpenCV frame, the ids, guides, the record and per-field Issues. A scene holds many tags and renumbers them through REF's numbering with a ledger. OpenCV reads every plan (ids, corners within 0.0075 mm, ChArUco corners) and its pose 25 degrees off is the plan's frame within 0.06 mm / 0.03 deg. Exports: SVG 1:1 (a tag and a scene sheet), PNG, STL (closed solids, stdlib), plan JSON. FastAPI serves it all on 127.0.0.1:5360.
