# M8b1: the mini CAD in the Studio

Built on branch `lane/M8b1` (worktree `aruco-studio-wt/M8b1`), 2026-10-16 night, from `main` at `3b56a22` (Merge 1), beside M8c. Zach was asleep: every open question took its recommended default (JSON file, no Save, the box net in 2D, the cockpit's stack). Not merged into `main`. ## What was built

| Piece | Where |
|---|---|
| File first: the Studio holds the design file's text (`GET /api/design`), writes every action as a new text (`PUT /api/design` with the hash it read) or through the old routes (a tag's settings), follows outside changes (`GET /api/events`), refuses every write while the file does not parse or is gone. No dirty state, no Save; Undo / Redo are a history of texts (an outside change is a step too) | `studio/src/store.ts`, `studio/src/api/events.ts`, `studio/src/api/client.ts` |
| The text written as the server writes it (sorted keys, indent 1, each untouched number as it was typed: `5.0` stays `5.0`), with each value's lines | `studio/src/model/json.ts` |
| The document's edits: a shape in a new sketch, holes, Extrude (or its height), ArUco Extrude on refs (a face list for several), move (a whole sketch moves its `at`), turn, copy (with its Extrude and tags), delete (a shape takes its body and every reference to it; a tag only its reference) | `studio/src/model/design.ts` |
| Shapes for drawing only (outline, holes, edges, face names, the net): the planner's loops stay the server's | `studio/src/model/shapes.ts` |
| The five shape tools and holes: R, C, P, O, H / Shift+H; drag or type (`80 50` Enter); handles (rectangle 8, circle rim, polygon points with Alt+click / Del, slot ends and width, a turn handle on every shape; 0.5 mm, 15°, Alt free) | `studio/src/canvas/Canvas2D.tsx`, `studio/src/sketch/handles.ts` |
| Extrude (E: typed height, the view goes 3D) and ArUco Extrude (A: the selection pre-picked; click a shape, or a face of the net drawn around an extruded shape; Shift+click more; Enter). The new tag gets the next free ids, is selected, the inspector on it | `store.ts`, `Canvas2D.tsx` |
| Live re-placement: a drag previews through `POST /api/design/preview` (15 Hz at most, newest wins, nothing written); on release the last preview's plans are drawn at once, then the file is written | `store.ts` (`preview`, `commitLive`) |
| The bottom toolbar: the nine tools and Search with their keys on badges, the lit tool, what it waits for and what you typed | `studio/src/app/BottomBar.tsx` |
| S = the command palette (cmdk). One list of commands feeds the toolbar, the palette, the keys and docs/STUDIO.md's table | `studio/src/app/Palette.tsx`, `studio/src/app/commands.ts`, `studio/src/app/App.tsx` (keys) |
| 3D: each Extrude a prism from its shape; each tag standing on its face by `pose_3d`; its own body drawn only near the face (a clipped skin; the prism is inset there), so pockets show; TransformControls on the selected shape's sketch (X / Y, 0.5 mm; a second one turns it about Z, 15°); the extrude arrow (0.5 mm steps, writes `height`); faces picked for ArUco Extrude (a circle's side says it is curved) | `studio/src/view3d/View3D.tsx`, `studio/src/view3d/Gizmo.ts` |
| Side-face tags in 2D: unfolded about their edge (the compile's canvas place) with a dashed `data-hinge` line | `Canvas2D.tsx` |
| The inspector: a shape's rows (place, turn, size, holes, the Extrude's height, the tags on it); a tag's first rows "On" (its reference, the shape a click away) and its face list; the target editor deleted | `studio/src/inspector/ShapeInspector.tsx`, `Inspector.tsx` |
| The file: the bar (path, state, "line N col M"), the File drawer (the text, the selection's lines lit, Reveal), New = a new file, Open by name or path, Save as | `studio/src/app/FileDrawer.tsx`, `Drawer.tsx`, `Dialogs.tsx`, `Toolbar.tsx` |
| The kit's primitives: `Kbd`, `ToolButton`, `NumberField`, `Field`, `Section`, `CommandPalette`; Tailwind 4 (theme and utilities, no preflight), `@base-ui/react`, `cmdk`, `lucide-react`, all pinned | `studio/src/kit/`, `studio/package.json` |
| Tests | vitest `studio/src/model/design.test.ts` (13: the text byte for byte with Python's, the edits, the faces and net, the handles); e2e `sketch.spec.ts`, `live.spec.ts`, `palette.spec.ts`, `drag3d.spec.ts`, `tools.spec.ts` (new), every older spec moved to shapes and the new keys |
| Docs | `docs/STUDIO.md` (rewritten: the file, the tools, the commands and keys table, the mouse) |

## Where the build differs from the note

| Note | Built | Why |
|---|---|---|
| snap to shape centres and edges within 6 px | the 0.5 mm grid only (Alt: no snap) | time; the done checks need the grid |
| one gizmo: translate X / Y and rotate about Z | two TransformControls on one sketch (move, and a ring that turns) | TransformControls has one mode at a time |
| Slot: drag the length, then the width | drag the length; the width is a quarter of it (type `L W` for both, or the width handle after) | one drag per shape |
| Hole: click inside a shape | also: type the diameter and Enter for the selected shape's centre | M8b1.1's "H inside it, 18" without a mouse |
| a typed shape | at the view's centre (the origin on an empty canvas), in a new sketch, the shape at the sketch's origin | |
| a handle | changes the shape's own `at` and size (the opposite edge stays) | the sketch's place stays the sketch's |
| `]` / `[` | turn the sketch when the shape is alone in it at its origin, else the shape | the forearm and drawn shapes turn about their centre |
| 3D bodies | drawn by the Studio from the file's shapes (display only); a tag's own body is drawn only near its face, the prism inset there | four tags on four faces of one box: each tag's body is the whole box; drawn whole they hide each other's pockets. Nothing goes to the planner |
| the File drawer marks the parse error's line | it shows the error's line and column and the last text that parsed | the server keeps and serves the last good text, not the broken one |
| Delete a tag | removes its ArUco Extrude (or its entry in a face list); the shape and the body stay | the shape is the user's drawing now (before M8b1 a tag's delete took its own sketch) |
| a new tag's ids | one past the largest id of its dictionary family; a face list shares its ids until Renumber | the old route's next free run needs a server change |
| Q / A / L / V / Shift+A | in the palette (and the top bar's buttons) | the letters are tools now (M8 §2.1) |
| (not in the note) | the palette's "ArUco: single / grid / ChArUco": on the selected shapes, else on a new 40 x 40 plate 3 mm thick (feature ids `tag<n>`, `board<n>`, `charuco<n>` as before) | a quick tag, and the older e2e specs' names |
| the kit | primitives in `studio/src/kit/` used by every new control; the other panels keep their look | M8b2 moves every panel onto the kit (and the light theme) |
